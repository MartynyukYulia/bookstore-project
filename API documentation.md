# Документація API модуля кошика (Cart API)

Цей файл містить повний технічний опис ендпоінтів для керування кошиком інтернет-магазину книг, налаштованих у Postman-колекції.

---

# Загальні технічні вимоги для роботи API

## 1. Авторизація користувача

Усі ендпоінти вимагають наявності активної сесії користувача.  
На сервері перевірка виконується за допомогою механізму сесій PHP.

Для успішного виконання запитів через Postman необхідно передавати Cookie:

```http
PHPSESSID
```

---

## 2. Заголовки запитів (Headers)

Для запитів, що надсилають дані на сервер (`POST`, `PUT`), обов'язково має бути встановлений заголовок:

```http
Content-Type: application/json
```

---

## 3. Базовий URL

```http
http://localhost/backend/modules/orders/
```

---

# Опис ендпоінтів та всі можливі варіанти відповідей сервера

---

# 1. Додавання книги до кошика

## 🔹 Основна інформація

- **Метод:** `POST`
- **URL:** `http://localhost/backend/modules/orders/cart_action.php`

---

## Опис

Додає обрану книгу до кошика авторизованого користувача.  
Якщо книга вже є в кошику, система автоматично збільшує її кількість на 1

---

## Структура тіла запиту (Body JSON)

```json
{
  "action": "add",
  "book_id": 1
}
```

---

## Всі можливі відповіді сервера

### Варіант А: Успішне додавання книги

**HTTP Status:** `200 OK`

```json
{
  "success": true,
  "message": "Книгу успішно додано до кошика",
  "count": 1
}
```

### Варіант Б: Помилка авторизації

**HTTP Status:** `401 Unauthorized`

```json
{
  "success": false,
  "message": "Потрібна авторизація"
}
```

### Причина виникнення
Помилка виникає, якщо користувач не передав Cookie `PHPSESSID` або сесія недійсна.
---

### Варіант В: Помилка валідації даних

**HTTP Status:** `400 Bad Request`

```json
{
  "success": false,
  "message": "Неправильний ID книги або параметр відсутній"
}
```

### Причина виникнення

Помилка виникає у випадках:

- параметр `book_id` відсутній;
- `book_id` має некоректний формат;
- значення `book_id` не є числом.

---

# 2. Отримання кількості позицій у кошику

## Основна інформація

- **Метод:** `GET`
- **URL:** `http://localhost/backend/modules/orders/cart_count.php`

---

## Опис

Повертає поточну загальну кількість позицій у кошику авторизованого користувача.

---

## Тіло запиту (Body)

Відсутнє.  
Для `GET`-запитів тіло не передається.

---

## Всі можливі відповіді сервера

### Варіант А: Кошик пустий

**HTTP Status:** `200 OK`

```json
{
  "count": 0
}
```

---

### Варіант Б: У кошику є товари

**HTTP Status:** `200 OK`

```json
{
  "count": 3
}
```

---

### Варіант В: Помилка авторизації

**HTTP Status:** `401 Unauthorized`

```json
{
  "success": false,
  "message": "Потрібна авторизація"
}
```

### Причина виникнення

Користувач неавторизований або відсутня активна PHP-сесія.

---

# 3. Оновлення кількості конкретної книги в кошику

## Основна інформація

- **Метод:** `PUT` (або `POST`)
- **URL:** `http://localhost/backend/modules/orders/cart_action.php`

---

## Опис

Змінює кількість конкретної книги в кошику користувача на вказане число.

Мінімально дозволене значення параметра `quantity` — `1`.

---

## Структура тіла запиту (Body JSON)

```json
{
  "action": "update",
  "book_id": 1,
  "quantity": 3
}
```

---

## Всі можливі відповіді сервера

### Варіант А: Успішне оновлення кількості

**HTTP Status:** `200 OK`

```json
{
  "success": true,
  "message": "Кількість книги оновлено до 3"
}
```

---

### Варіант Б: Помилка валідації кількості

**HTTP Status:** `400 Bad Request`

```json
{
  "success": false,
  "message": "Кількість товару повинна бути не менше 1"
}
```

### Причина виникнення

Помилка виникає, якщо:

- параметр `quantity` менший за 1;
- `quantity` не переданий;
- значення має некоректний формат.

---

### Варіант В: Товар не знайдено в кошику

**HTTP Status:** `404 Not Found`

```json
{
  "success": false,
  "message": "Цієї книги немає у вашому кошику"
}
```

### Причина виникнення

Система не знайшла книгу з указаним `book_id` у кошику поточного користувача.

---

# Додаткові примітки

## Формат даних

Усі відповіді сервера повертаються у форматі:

```json
application/json
```

---

## Кодування

Рекомендоване кодування:

```text
UTF-8
```

---

## Підтримувані HTTP-методи

| Метод | Призначення |
|---|---|
| GET | Отримання даних |
| POST | Створення або оновлення даних |
| PUT | Оновлення даних |

---

# Висновок

API модуля кошика забезпечує базову функціональність для роботи з кошиком інтернет-магазину книг:

- додавання товарів;
- перегляд кількості товарів;
- оновлення кількості товарів.

Усі ендпоінти підтримують JSON-формат обміну даними та використовують механізм авторизації через PHP-сесії.
